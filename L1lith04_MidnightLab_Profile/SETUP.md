# Publish the Midnight Lab profile

## What this package contains

- `README.md`: the public profile content
- `assets/midnight-lab-banner.svg`: a decorative midnight-lilac header
- `assets/profile-photo.jpg`: your edited portrait (compressed to less than 1 MB)

## Instructions

1. Go to https://github.com/new and create a **public** repository named exactly `L1lith04`, under the `L1lith04` account. This is NOT your private `medrag-assistant` repository.
2. If you are creating it from scratch, you can leave the default file initialization choices off, then upload the contents of this folder. Alternatively, create it with a README first, then replace README.md and upload the `assets` folder.
3. On the new **public** `L1lith04` repository, choose **Add file > Upload files**. Upload `README.md` and both files inside `assets/`, maintaining the directory structure. For reliable paths, drag the **assets folder** into GitHub or use VS Code/Git to push the package contents.
4. Commit the change. Open https://github.com/L1lith04 to view the profile.
5. Check that the banner and portrait display correctly. If a picture is missing, ensure the image paths match `assets/midnight-lab-banner.svg` and `assets/profile-photo.jpg` exactly.
6. Update project statuses and public links whenever a repository or write-up is actually ready.

## A safer alternative if the profile README repo already exists

Clone `https://github.com/L1lith04/L1lith04.git` into a NEW local folder (not inside medrag-assistant). Replace its root `README.md`, copy `assets/`, then commit and push it. This keeps the two repositories separate.

## Important

- Do not upload patient documents, conversation archives, model caches, vector databases, `.env` files, tokens, or private MedRAG source code.
- Keep `L1lith04/medrag-assistant` private. Mentioning it in the profile does not change its visibility.
- The profile repository is PUBLIC and will show the image included here.
- GitHub does not show a private repository to other visitors just because you mention its name.
